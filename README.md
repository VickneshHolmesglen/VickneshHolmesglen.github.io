# Portfolio site

Static site for GitHub Pages. No build step.

- Content: edit `projects.js` only (name, links, projects, skills table).
- Preview locally: open `index.html` in a browser.
- Publish: push this folder to a public repo named `VickneshHolmesglen.github.io`, then in the repo
  go to Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
  The site appears at https://vickneshholmesglen.github.io a minute or two later.
